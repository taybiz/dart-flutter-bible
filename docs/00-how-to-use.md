# 0. How to Use This Bible

Read it before you bootstrap a Dart/Flutter project, and before you review one.

- **Before bootstrapping** any Dart/Flutter project: read it first, then work through §9 (the bootstrap checklist) in order.
- **Before reviewing** any Dart/Flutter code: read it first; §10 is the checklist to answer against.
- **When an agent is assigned** Dart/Flutter work: the `dart-clean-architecture` skill loads first and points here. If it doesn't load, read this doc anyway.
- **When scaffolding a new repo**: copy the operating-doc templates (`templates/` — `AGENTS-<topology>.md`, `BACKLOG.md`, `CHANGELOG.md`) and fill in the placeholders. They are the minimal starting skeleton, so a new project begins from a standard AGENTS/BACKLOG/CHANGELOG rather than inventing its own.
- **What you are holding**: the bible is roughly two thirds Dart doctrine and one third Flutter. The Dart doctrine is the foundation; Flutter is the outermost ring of the same design.
